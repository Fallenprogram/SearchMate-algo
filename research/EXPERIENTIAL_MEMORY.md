# Evidence-reviewed process memory

Memory version: **m1-process**. This public rendering preserves the narrow lessons already admitted in the local research record; it does not invent a new measured memory benefit. The original [m0-bootstrap file](archive/pre-retrospective-2026-09-11/research__EXPERIENTIAL_MEMORY.md.txt) is preserved unchanged.

## M1-P001 — Account for startup without changing game semantics

**Trigger: ** planning local short-game screens for the audited Numba engine family. **Evidence: ** the completed v9–v11 window spent about 69.6% of its 58-game elapsed time on startup. **Action: ** use a source-bound warmed wrapper only after reset equivalence and game-boundary acknowledgements; choose the mode before scoring and retain fresh-process full-clock/package checks. **Counterevidence and limits: ** local Windows imports need not resemble platform imports; a warm wrapper can leak state. No playing-strength improvement follows from lower experiment overhead.

## M1-P002 — A proxy is not a competitive qualification

**Trigger: ** better static accuracy, node counts or a selected-position repair. **Evidence: ** v9/v11, v12/v13 and the v31 neural-only screen show why positive proxies were insufficient; v7 and v37 earned separate game evidence. **Action: ** freeze criteria before games, preserve failed/incomplete attempts, and distinguish a newly defined experiment from an extension of a failed sample. **Counterevidence and limits: ** a small failed screen does not prove that a feature has zero benefit everywhere. Maintenance uses its own declared targeted criteria, without pretending to pass a broad strength gate.

## M1-P003 — Trace the decision before assigning a cause

**Trigger: ** a rated loss disagrees with a bounded reference estimate, or additional search does not choose the expected alternative. **Evidence: ** round 59 recapture investigations, round 82 king-safety traces and round 103's unresolved continuation. **Action: ** record completed search behavior, feature coverage and comparable child estimates with matching available history; retain missing, unstable or non-comparable estimates as unknown. **Counterevidence and limits: ** third choices can be ungraded; reference bounds, mate scores and incomplete iterations constrain interpretation. Neither “evaluation alone caused it” nor “more time fixes it” follows without evidence.
